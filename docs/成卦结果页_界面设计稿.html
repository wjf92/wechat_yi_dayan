01精简后的三段结构

去掉了数据 chips、营数公式行、参考依据标签、独立「主断爻辞／参考爻辞」卡片、六爻折叠、变卦区大段模式说明。整页只剩三个卡片：

区段内容
① 总结一张结论卡，内部分三行：动爻说明 / 宜变之爻 / 占断结论
② 本卦卦象（带标记）＋ 卦辞 ＋ 六爻爻辞全文，主断／参考用括号标在爻辞前
③ 变卦一至两张之卦卡，每张含小卦象、卦名、完整卦辞＋六爻爻辞全文

本卦与变卦的爻辞用同一套清单样式，读法一致；变卦不再只列「对应爻辞」，避免断占时要另行翻书。

02总结区的三行句式

结论卡内固定三行，每行一个行首标签，变量只由 values 算出，不需要人工撰写：

动爻动爻数量为 2，分别为九四、九五
宜变卦之营数为 50，算得宜变之爻为九五，宜变之爻为动爻
结论以本卦九五爻辞为主断，亦应参考变卦的卦辞
行句段取值
1动爻数量／名称营数为 6、9 的爻数；按「初九、九二…上六」称呼
2营数 → 宜变之爻 → 相值S = Σ六爻营数；r = 55 − S 12 步循环数爻得爻题；判定是否为动爻
3主断结论按动爻数与相值结果选：本卦某爻辞／本卦卦辞／本卦与之卦合参／之卦卦辞

三行是同一张卡里的行，不是三张卡；第三行朱红加粗，作为「主断结论」的落点。静卦特例：第二行写「不必起天地之数，故无宜变之爻可算」。

03爻辞内联标注

位置标注样式
本卦 · 主断爻（主断）朱红加粗，整行淡红底
本卦 · 未相值动爻（参考）浅灰小字
变卦 · 新变出的爻无文字标注爻题朱红，与卦象里的朱红爻画对应

两处的六爻爻辞都一次列全、不再折叠，也不另开卡重复主断爻辞。

04卦象标记（保留）

标记视觉含义
变爻朱红实心爻画 ＋「变」九／六，主观变动意向
宜变之爻该行浅灰底＋墨黑虚线＋「宜」虚框天地之数算出的客观位置
主变数朱红「主变数」胶囊两者相值，该爻为主断依据

仍只用朱红一种强调色；变卦小卦象中，新变出的爻画也用朱红。

05变卦区的展示规则

情形展示
动爻 0一句空态说明，不另列卦
动爻 1，相值一张之卦卡，注明「单变＝齐变」
动爻 2～3，相值分别展示单爻变卦＋多爻齐变卦
动爻 1～2，不相值仅齐变之卦，灰态「仅作参考」
动爻 3，不相值齐变之卦标「与本卦合参」
动爻 4～6齐变之卦标「主断依据」，红边强调

每张卡都给全卦辞＋六爻爻辞；卡片标题只写「单爻变卦／多爻齐变卦」，变化范围放进右侧小标签。之卦同样是 64 卦之一，按卦序号从同一张 384 爻辞表取六条即可，不需要另建数据。

06落地前要补的两处

计算：utils 层加纯函数，由 values 求出 S / r / yiIndex / matched / singleHex / allHex / mode 与三行结论文本。旧占例只存 values，全部可重算，无需数据迁移。

数据：现有 hexagrams.js 只有 64 卦名与卦辞，缺 384 爻爻辞；本卦、单爻变卦、多爻齐变卦的完整爻辞都要从这张表取。设计稿中的爻辞为示例文本，落地前需补齐并按卦序号＋爻位索引。

设计稿里的爻辞与卦辞用于验证版面，不参与占断计算；结论只由营数、宜变之爻位、动爻数三者推出。
